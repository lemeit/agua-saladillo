# Protocolos de ensayo (PDF originales)

Copias de los protocolos de análisis de agua que la Municipalidad de Saladillo publica en `?q=analisis_2025` y `?q=analisis_2026`, organizadas por año de publicación. Se van a sumar acá cuando corramos el GitHub Action de descarga (disparo manual) — todavía no implementado.

Objetivo: tener el PDF original versionado junto a los datos que salen de él, para poder volver a la fuente si hace falta reprocesar o verificar un valor.

- `2025/` — protocolos publicados en `analisis_2025`
- `2026/` — protocolos publicados en `analisis_2026`

Nombrado sugerido: `<numero_protocolo>_<fuente_slug>_<fecha_iso>.pdf` (ej. `069178_bomba-1_2025-01-02.pdf`) cuando el protocolo trae número; si no, se usa el nombre de archivo original del sitio municipal.
